Fixture: blokering (to tilstande)

Opdigtet UI uden login. A) kan omformuleres → «Brug forslaget». B) kan ikke → kun vejledning (ikke kopierbar til afsendelse).

A) Kan omformuleres (praktisk kerne)

Beskeden blev ikke sendt. Den kan opfattes som sårende eller som en ordre til den anden. Ret den og prøv igen.

Markeret tekst: Du skal hente kl. 16, punktum.

Forslag til omformulering

Kan vi aftale afhentning kl. 16?

Forslaget kopieres til skrivefeltet. Du sender selv — det tjekkes igen.

B) Kan ikke omformuleres (ren kritik)

Beskeden blev ikke sendt. Den kan opfattes som sårende eller som en ordre til den anden. Ret den og prøv igen.
